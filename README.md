## JEngine

Dated: 2016-11-30

This is actually a really interesting version of JEngine... it inspired me to learn OpenGL because BGFX wasn't fun to work with, at least back then.

As show by this exchange lol:

> Someone else: Why? What will come from using OpenGL instead of BGFX? They're both low level but I thought BGFX was high enough to be human readable without a PhD in sex?
