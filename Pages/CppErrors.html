C++ compiler errors and what they mean

C++ compiler errors can be confusing and hard to work out. Alot of the time they lack clarity in what they mean. The table below will explain some errors meanings.
It is worth noting that different compilers word the errors slightly differently, but it should be easy to work out what error means what. For the examples I will be using the C++ compiler which comes with Microsoft Visual Studio.

Error message Meaning
Expected a ';' There is a line which is missing a semicolon on the end of it.
No exsisting conversion between [type 1] and [type 2] This means that the computer cannot automatically convert between one data type and the other.
Cannot open include file [file name]. No such file or directory. There is a typo in the name of the include file, or it doesn't exist, which is preventing the compiler from finding it.
Too few arguments in function call There is a function being called which doesn't have enough parameters being passed through it.
Incomplete type is not allowed. This is an error message which has a few useages. It is commonly used to express if the program is trying to create a variable of type 'void', but can also describe classes where there is only a forward declaration.
