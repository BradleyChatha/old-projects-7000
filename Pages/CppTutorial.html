Indroduction

This tutorial is designed to be a help for those who wish to learn C++. C++ is a programming language which is very commonly used for hobbiest and professionals alike.
C++ was first released in 1983 by Bjarne Stroustrup. While it is commonly thought as a subset of C rather than it's own language this is incorrect.

Compilers, IDEs, and text editors

At the least needed for C++ is a compiler. A compiler turns human readable code into machine code, which can be ran by the computer.
There are many compilers and they're platform specific, but for this we'll focus on Windows. Linux users already have a compiler installed.
There are two main options when programming in C++. One is to use a text editor with a command line compiler and the other is to use an Integrated Development Environment (IDE).

There are many kinds of text editors and most have syntax highlighting.
Two very common text editors are Notepad++ and Visual Studio Code. Both have their advantages and disadvantages.
Notepad++:
+ Syntax highlighting
+ Settings easy to navigate
+ Easy to add new languages
- Limited predictive text

Visual Studio Code:
+ Syntax highlighting
+ Settings easy to navigate
+ Easy to add new languages
+ Has support for addons
- Better predictive text than Nodepad++ but still not as good as a dedicated IDE.

There are two major command line compilers which I will cover. MinGW and Clang.
Both are about the same as each other in terms of what they do, it's down to personal preference on which you choose.
MinGW uses the command g++ to compile files and clang uses the command clang++.

IDEs are a combination of a text editor and a compiler all in one package. They have syntax highlighting and (for the most part) reliable predictive text. One of the most popular IDEs is Microsoft Visual Studio.

Writing to the screen.

One of the most basic things to do in any programming language is to write something to the console, traditionally the words "Hello, World!". Look at the following C++ code, this is an example of how to write to the console in C++. Any time you see "//" there is a comment after that position and the writing on the rest of the line will not be compiled. 

                                    
//This line tells the compiler that there is another file to be used.
//This is where the information the 'cout' line is.
#include <iostream>
                                            
//This tells the compiler that we want to use code which belong to the group, or namepsace,"std".
//This is the C++ Standard Library. 
using namespace std;
                                   
//This is a function. This is the first place the compiler goes to when the program is being built.
//The words inside of the brackets will be discussed later.
int main(int argc, char** argv)
{
    //This is how words are being wrote the console. The 'cout' means character out.
    //The following '<<' dictates that is going to cout. In this case it is a string.
    //Strings are shown as words inside of speech marks ("), there must be an opening speech mark.
    //'endl' means end line. This can also be done with '\n'. It forces the next information to be printed into the line below.
    cout << "Hello, World!" << endl;
    
    ///This tells the function that it has ended now.
    return 0;
}
